# PRD：标书自动化工具（MVP）

## 概述
目标是构建一套能将甲方招标文件自动解析并生成可编辑投标草稿的工具，长期目标是在 Copilot Studio 中开发一个 Agent，使销售/投标团队能通过对话式界面完成上传、审阅、生成与自动排版工作。理想结果：上传招标文件后，系统自动识别与应标相关的条款、对比投标知识库并生成可编辑草稿，适配度≥70%。

本 PRD 聚焦第一阶段（MVP）的快速交付目标与可验收特性，并新增了基于 Copilot Studio 开发 Agent 的实现细节与接口要求。

---

## 理想结果（长期目标）
- 上传甲方招标文件，系统能自动识别关于应标的条款与要求。
- 对比投标文件知识库（已有模板、历史中标书、公司资质与产品表），自动生成一份可编辑的投标草稿（Word），适配度≥70%。
- 通过 Copilot Studio 部署的 Agent：可通过自然语言与 Agent 交互，完成上传、复核、二次编辑建议、排版指令与输出管理。

---

## 第一阶段（MVP）目标
1. 上传甲方招标文件（PDF/扫描件/Word），并转换为可编辑 Word（.docx）。
2. 自动高亮文件中与“必须/废标”相关的条款（在转换后的 Word 中进行 highlight 并记录页码）。
3. 自动生成投标风险提示文件（独立文档），列出风险条款、简要说明与对应页码。
4. 自动生成简单的投标草稿（基础章节：公司简介、商务标准通用条款、必备合规声明等）。
5. 支持上传销售员二次编辑的标书，并对标书进行自动排版（封面、目录、页眉页脚、章节样式、字体与缩进），生成标准排版的可编辑 Word。
6. 根据选型工具输出（CSV/JSON/Excel），自动生成招标文件要求格式的设备技术清单（供货清单）。
7. 在 Copilot Studio 中实现一个交互式 Agent（Agent 1.0）：处理文件上传、展示高亮结果、生成草稿、触发自动排版与导出，并能接受用户指令如“请高亮风险条款”“按公司模板排版并导出Word”。

## Copilot Studio Agent 设计（新增）
目标：用 Copilot Studio 快速迭代并部署一个 Agent 来串联上传、解析、生成与导出流程，提升一线销售的使用体验。以下为 Agent 的能力与实现细节：

1. Agent 能力清单（Capabilities）
   - 文件接收：通过 Web 上传或集成上传 API，支持 PDF/扫描图像/Word/ZIP（批量）。
   - 文档解析执行器：触发后端文档解析任务（异步），并在完成后返回解析摘要与高亮结果。
   - 风险识别与提示：展示识别出的风险条款、页码，并能导出风险提示文件。
   - 草稿生成：基于知识库与模板生成初版投标草稿，支持参数化占位符替换请求。
   - 排版指令：接收“排版”命令并调用排版服务生成标准 Word。
   - 变更审阅：展示对比视图（原始->草稿->排版后），并记录审阅批注。
   - 导出与交付：提供下载链接（docx、pdf、excel），并支持发送到指定邮箱/Drive。

2. Agent 接口与对话流（示例）
   - 用户："上传招标文件"
   - Agent："已上传，正在解析。预计 3-6 分钟。是否同时触发风险识别与草稿生成？"
   - 用户："是，先生成草稿并高亮风险条款。"
   - Agent："已生成：高风险条款 3 条（见摘要）。草稿已生成（可编辑），是否预览或直接排版导出？"
   - 用户："预览并排版导出 Word。"
   - Agent："已排版完成，下载链接：...；已发送至 xxx@example.com。"

3. Copilot Studio 集成点
   - 将 Agent 的 intents/skills 定义在 Copilot Studio（文件上传、解析、生成、排版、导出、审阅）。
   - 后端任务由微服务实现（文档解析服务、NER/条款识别服务、草稿生成服务、排版服务、存储服务）。Agent 通过 REST/gRPC 调用这些服务。
   - 使用 Copilot Studio 的对话状态管理追踪任务进度，使用 events/notifications 推送异步结果给用户。

4. 安全与权限
   - 上传文件在存储中加密，权限控制基于 GitHub/OAuth 或企业 SSO。
   - Agent 操作日志、审计记录与文件访问权限需可查询与回溯。

5. 训练/提示工程（Prompting）
   - 为条款识别与草稿生成设计可复用的 Prompt 模板，并对关键抽取任务使用 few-shot 示例。
   - 将人工标注的条款样本纳入微调或检索增强生成（RAG）流程，提升召回率与准确率。

6. 可扩展性
   - Agent 接口设计需支持插件式添加新的解析器或导出格式（如 PPT、Excel 报表），并支持多语言招标文件（中文/英文）。

---

## 输入与输出
- 输入：甲方招标文档（PDF/扫描图像/Word）、已有投标知识库（历史标书/模板）、选型结果（CSV/JSON/Excel）、销售员上传的草稿（可选）。
- 输出：
  - 可编辑的 Word 投标草稿（docs/… .docx）
  - 风险提示文档（Markdown/Word/PDF，包含页码）
  - 高亮标注的原始招标文件（转成 Word 并高亮）
  - 设备技术清单（Excel/CSV + 嵌入到 Word）

## 阶段里程碑（建议）
- Week 0-2：数据采集与样本准备（收集 10-20 份招标文件与人工标注的风险条款样本）。
- Week 2-4：开发文档解析与 OCR 管道；实现 Word 转换与基本高亮功能；在 Copilot Studio 中搭建 Agent 原型（intent + file upload flow）。
- Week 4-8：实现条款识别与风险提示文档生成；初版投标草稿自动生成逻辑；Agent 支持草稿生成命令与预览。 
- Week 8-10：自动排版与设备清单生成功能；在 Copilot Studio 中完成排版命令与导出集成。
- Week 10-12：测试与迭代，评估适配度指标并优化模型/规则；用户验收测试（销售团队）。
